# 零基础教程：从装环境到导出第一条片子

假设你只会开关软件、复制粘贴。按顺序做完，大概 40 分钟，其中一半时间在等视频生成。

> 已经跑起来了、只想学怎么用？直接跳到 [第 4 节](#4-做第一条片子)。

---

## 0. 先把话说明白

这个工具**不是网页版**，没有注册就能用的官方网址。它跑在**你自己的电脑或服务器**上。

- 好处：素材不上传第三方，模型 key 是你自己的，用多少花多少，没人抽成。
- 代价：第一次要装环境，要自己申请模型 key。**下面两步就是干这个的。**

模型费用另算：一条 15 秒的片子，用便宜的视频模型大约几毛到几块。这个工具本身不收费。

---

## 1. 装运行环境（Bun）

Bun 是个程序运行环境。装一次，以后不用管。

### Windows

1. 按 `Win` 键，输入 `powershell`，回车。会出现一个蓝底命令行窗口。
2. 复制这一行，粘进去（在窗口里点右键就是粘贴），回车：

```powershell
powershell -c "irm bun.sh/install.ps1 | iex"
```

3. 等它跑完，看到 `bun was installed successfully` 之类就成。
4. **关掉这个窗口，重新开一个**。这一步不做，下面会提示找不到 bun。

### macOS

打开「终端」（聚焦搜索 `Terminal`），粘这一行回车：

```bash
curl -fsSL https://bun.sh/install | bash
```

装完同样关掉终端、重新打开。

### 验证

新窗口里输入：

```bash
bun --version
```

打印出 `1.x.x` 就是成功。报「不是内部或外部命令」/`command not found`，就是没重开窗口。

## 2. 把程序跑起来

### 拿到代码

已经装了 git 的话：

```bash
git clone https://github.com/chanjom/geekreel.git
cd geekreel
```

没装 git：打开 <https://github.com/chanjom/geekreel>，点绿色 `Code` → `Download ZIP`，解压，然后在终端里 `cd` 进解压出来的文件夹（小技巧：Windows 资源管理器地址栏输入 `cmd` 回车，就直接在这个文件夹打开命令行）。

### 一键安装并启动

**Windows**：

```bat
scripts\setup.cmd
```

**macOS / Linux**：

```bash
chmod +x scripts/setup.sh
./scripts/setup.sh
```

它会做三件事：装依赖、编网页、启动服务。第一次 1–3 分钟，之后几秒。

看到下面这行就成功了：

```
[vw] 视频工作台 server 已启动: http://127.0.0.1:4780
```

**这个窗口不要关**。关掉服务就停了。

### 打开

浏览器输入 **http://127.0.0.1:4780**

不需要登录。左边一排菜单，中间是内容区。

> 下次再开：Windows 跑 `scripts\start.cmd`，mac 跑 `./scripts/start.sh`。不用重新装。

## 3. 配一个能用的模型 key

**没有 key，界面能点，但生成会报错。** 这一步不能跳。

到左边 **模型** 页。会看到一排预置厂商，分成「文本 / 图片 / 视频 / 语音」四类。

新手最小配置：**一个文本模型 + 一个视频模型**，够做出片子了。想加配音再加语音模型，想自定义画面再加图片模型。

### 3.1 文本模型（写剧本、拆分镜）—— 推荐 DeepSeek

1. 打开 <https://platform.deepseek.com>，手机号注册，登录。
2. 左边「API keys」→「创建 API key」→ 复制那串 `sk-` 开头的字符。
3. 新账号一般有免费额度；没有就充 10 块钱，够写很多剧本。
4. 回到「模型」页 → 点 **DeepSeek** → 把 key 粘进「API Key」→ 保存。

### 3.2 视频模型（真正出画面）—— 三选一

| 厂商 | 去哪申请 | 特点 |
|---|---|---|
| **通义万相**（阿里云百炼） | <https://bailian.console.aliyun.com> → 开通 → API-KEY | 中文场景稳，有免费额度，新手首选 |
| **豆包 Seedance**（火山方舟） | <https://console.volcengine.com/ark> → 开通模型 → API Key | 出片质量好，需要实名 |
| **可灵**（快手） | <https://klingai.com> → 开放平台 | 动作自然，价格偏贵 |

申请流程都是：注册 → 实名（国内厂商都要）→ 开通对应模型 → 创建 API Key → 复制。

回到「模型」页 → 点对应厂商 → 粘 key → 保存。视频这类通常还要选一下模型名（如 `wan2.1-t2v-turbo`），页面上有下拉框。

### 3.3 语音模型（可选，想要配音再配）

- **豆包语音**：火山引擎 → 语音技术 → 需要 `APP ID` + `Access Token` 两个值（不是普通 API Key，别填错）
- **通义 CosyVoice** / **OpenAI TTS** / **MiniMax**：同上，粘 key 即可
- **不想花钱**：Windows 版有「本机配音」，用系统自带的语音引擎，离线、免费、不限字数，音色机械但能听

### 3.4 检查配好了没

「模型」页每张卡右上角有状态。配好的会显示成已启用。再去 **任务中心** 看有没有红色报错。

## 4. 做第一条片子

打开首页。中间是一个输入框，问「想做什么视频」。

### 第 1 步：说清楚你要什么

不要写「做个好看的视频」。写具体一点，比如：

> 深夜便利店，一个加班到凌晨的女孩买关东煮，店员多送了她一颗鸡蛋。15 秒，温暖治愈。

越具体越好：**地点 + 人物 + 发生什么 + 情绪 + 时长**。

### 第 2 步：选风格

风格决定画风和提示词。内置两套：

- **上美影风**：上海美术电影制片厂那种手绘动画感，适合故事、国风
- **手绘白板**：暖色纸底 + 素描线条，适合讲解、科普

选一个，然后让它出剧本。

### 第 3 步：改剧本

出来的剧本会拆成几个镜头，每个镜头有画面描述和台词。**不满意就在对话里直接说**：

- 「第二个镜头改成俯拍」
- 「台词太文了，口语一点」
- 「去掉旁白，只留对白」

改到你觉得可以为止。这一步花的钱很少（文本模型），值得多改几轮。

### 第 4 步：定妆

系统会为每个角色生成一张定妆照。这张图会作为后面所有镜头的参考，**保证人物长得一样**。

不满意就重生成，直到脸对了为止。定妆这一步别省，脸不对后面全废。

### 第 5 步：出片

点「出片」，任务进队列。

- 一个 15 秒的片子大概 3–10 分钟，看厂商排队
- **可以关掉浏览器**，任务在后台继续跑，回来在「任务中心」看进度
- 出完的画面进 **资产库**，也自动挂到这个项目上

### 第 6 步：配音（可选）

到 **时间线** 页。画面和字幕已经自动铺好了。

1. 选一个音色，点试听
2. 满意后点配音 —— 对白镜会先出语音，再对口型；旁白只铺声音
3. 想要背景音乐、环境音，下面有对应的音轨可以加

> 配音是**手动**的，不会在出片时自动铺。这是有意的：先看画面对不对，再决定用什么声音。

### 第 7 步：导出

时间线右上角「导出」→ 选分辨率（默认竖屏 1080×1920）→ 勾「烧字幕」→ 导出。

等进度条走完，成片在项目目录的 `export/` 里，同时进资产库。点一下就能播放或下载。

**第一条片子做完了。** 后面就是重复：换选题、换风格、加快节奏。

## 5. 常用操作速查

| 想做什么 | 去哪 |
|---|---|
| 找当下热点选题 | **雷达** —— 微博/知乎/抖音/B站实时榜，看到能直接「做成视频」 |
| 拆解别人的爆款 | **分析** —— 粘链接或从资产库选，出钩子/节奏/分镜报告 |
| 把小说改成短剧 | **小说转短剧** —— 上传 txt/md，先出人物档案和事件清单 |
| 做连续剧 | **连载** —— 定妆照锁进后续每一集，人物不会变脸 |
| 精细控制每个镜头 | **画布** —— 节点连线，自己搭流程 |
| 看成片花在哪 | **模型** 页底部 30 天花费汇总 |
| 换主题/字体大小 | **设置** |

## 6. 报错对照表

| 报错 | 什么意思 | 怎么解决 |
|---|---|---|
| `未配置端点` / `no endpoint` | 这一类能力还没有 key | 去「模型」页配对应的厂商 |
| `401` / `invalid api key` | key 错了 | 重新复制，注意别带空格 |
| `403` / `insufficient balance` | 欠费或没开通 | 去厂商后台充值 / 开通模型 |
| `429` / `rate limit` | 请求太频繁 | 等几分钟；或把并发调低 |
| `model not found` | 模型名不对 | 「模型」页把模型名改成厂商文档里写的 |
| `role must be specified` | 多图输入没标角色 | 本仓库已处理；如果还出现，把提示词里的参考图减到一张 |
| 视频合成失败 | ffmpeg 问题 | 装 ffmpeg，或在 `.env` 里写 `VW_FFMPEG=/usr/bin/ffmpeg` |
| 字幕是方块 / 乱码 | 字体缺中文字形 | 装中文字体；Linux 上 `apt install fonts-noto-cjk` |
| 配音没声音 | 没点配音 | 时间是手动铺的，去时间线选音色再点一次 |
| 页面白屏 | 没编译 | 跑 `bun run build` 重启 |
